# Rehearsal checklist (on the real booth devices)

Do this once on every device that will be at the booth, ideally the day
before. Allow about 20 minutes per device, plus time with a few students.
Write problems in the notes column and tell your teacher, or open an issue.

## 1. Device setup

| ✓ | Check | Notes |
|---|---|---|
| ☐ | Charger works; plan to keep it plugged in all night | |
| ☐ | **Auto-lock / sleep turned off** (or set to the longest time) | |
| ☐ | Notifications off (Do Not Disturb / Focus) so pop-ups don't cover the game | |
| ☐ | Screen brightness at maximum (outdoor light) | |
| ☐ | Browser zoom at 100% | |
| ☐ | Volume up; test the speaker, or a portable speaker if it's too quiet | |

## 2. Getting the game running

| ✓ | Check | Notes |
|---|---|---|
| ☐ | **Laptop:** `python3 -m http.server 8000` in the game folder, open `http://localhost:8000` | |
| ☐ | **Tablet/Chromebook using the website:** open the URL once on good Wi-Fi | |
| ☐ | Website only: turn Wi-Fi **off**, reload, and the game still loads (offline cache works) | |
| ☐ | Fullscreen button works (iPad/iPhone: Share → Add to Home Screen, open from the icon) | |

## 3. Playing (with real kids if possible)

| ✓ | Check | Notes |
|---|---|---|
| ☐ | Swipes feel instant; the claw trail follows the finger | |
| ☐ | The title screen doesn't scroll, zoom or open menus while swiping | |
| ☐ | Sound plays after the first tap (slices, bombs, the frenzy growl) | |
| ☐ | Bombs are easy to spot and avoid | |
| ☐ | Panther Frenzy kicks in at 10 seconds left | |
| ☐ | No stutter during the frenzy; note the device model if it lags | |
| ☐ | Turn the device sideways and back mid-round: the game keeps going | |

## 4. Calibrate the prizes

Have **at least 5 different students** (a range of ages) each play one
Challenge round. Write down their scores:

| Player (initials only) | Age group | Score |
|---|---|---|
| | | |
| | | |
| | | |
| | | |
| | | |

Then set the prize scores in staff mode. A rule of thumb:
- **Bronze**: most first-timers reach it (around the lowest score above).
- **Silver**: about half the players.
- **Gold**: only good players.
- **Legendary**: rare. Only the best score you saw, or higher.

Use the **same numbers on every device**.

## 5. Staff mode and prizes

| ✓ | Check | Notes |
|---|---|---|
| ☐ | 5 taps on the moon opens the PIN pad | |
| ☐ | Set the station letter (different per device), event word (same everywhere) and a new PIN | |
| ☐ | Kiosk mode on; the results screen returns to the title after the idle time | |
| ☐ | Win a prize (set Bronze very low to test), hold the "Prize desk use only" box about 3 s, and it says CLAIMED | |
| ☐ | On a **different** device, "Check a prize code" gives the same code | |
| ☐ | Set the Bronze score back to the real value afterwards! | |
| ☐ | Reset the leaderboard so the event starts clean | |

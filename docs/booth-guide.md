# Boo Bash booth guide

A one-page guide for whoever runs the Panther Slash booth. Print it and keep
it at the table.

## Before the doors open (10 minutes per device)

1. **Start the game.** On a laptop, run the local server from the README and
   open `http://localhost:8000`. That needs no Wi-Fi at all. If a device
   uses the website instead, load it before the event and **keep the tab
   open**: until the offline update is added, reloading needs internet.
2. **Open staff mode.** On the title screen, tap the **moon 5 times quickly**,
   then enter the PIN (default `1031`).
3. Set these, then press **Save**:
   - **Station letter:** a different letter on each device (A, B, C...).
     Write it on a sticky note on the device.
   - **Event word:** the **same** secret word on every device. Don't use the
     default, because the code is public.
   - **New PIN:** pick one and tell only the volunteers.
   - **Kiosk mode:** on. Abandoned screens go back to the title after the idle
     time.
   - **Show Classic mode:** turn it off if every paid play should be the
     Challenge.
   - **Round length and prize scores:** use the **same values on every
     device**, or prize codes won't check out across devices.
4. Press **Exit**, turn the volume up, and tap the fullscreen button
   (bottom right).
5. Play one round yourself to check that sound and touch work.

## During the event

- Each $2 play is one **Boo Bash Challenge** round.
- If the player reaches a prize score, the **prize screen** shows:
  - the tier (Bronze, Silver, Gold or Legendary Panther), the score, and a
    **clock that ticks every second**
  - the **round** (like `B-047`) and a **4-letter code**
- **To hand out a prize:**
  1. Check that the screen is live, with the clock ticking. A screenshot
     doesn't tick.
  2. **Hold the "Staff: hold here to claim" box** for about a second until it
     turns red and says **CLAIMED**.
  3. Give the prize. A screen that already says CLAIMED gets no second prize.
- **Checking a prize from another device** (for example, the player walked
  over and the screen changed): open staff mode on any booth device, go to
  **Check a prize code**, and enter the round and score. If the code shown
  matches what the player has, it's real. If the round was played on that same
  device, it also tells you whether it was already claimed.
- **Prizes won on this device** in staff mode lists every prize won on that
  device, with codes and claim times.

## Problems

| Problem | Fix |
|---|---|
| No sound | Tap the screen once (phones need a tap first), and check the speaker button isn't muted. |
| Screen not full | Tap the fullscreen button. On an iPhone or iPad: Share → Add to Home Screen. |
| Frozen or weird | Reload the page (on the website this needs internet for now). Scores and settings are kept. |
| Forgot the PIN | Clearing the browser's site data resets everything (scores too), and the PIN goes back to `1031`. |
| Reset the leaderboard | Staff mode → Reset leaderboard → tap it twice. |

## Privacy

Players only ever enter **3 initials**. Never ask for or write down a name,
email or phone number on the device.
